# Котозайцы для Hyprland

Прозрачный котозаяц на GTK4 + gtk4-layer-shell. Он полностью виден у нижнего края, плавно разгоняется при прогулке и мягко разворачивается у краёв. Прыжки и падение используют отдельную анимацию; при падении котозаяц ускоряется под действием гравитации и пружинит при приземлении. Полноэкранный слой не обрезает его, если потянуть вверх. Левый клик запускает прыжок. Зажми его за голову и потяни — если включено прикрепление, он повиснет на курсоре и задрыгает лапами; отпусти, чтобы он упал на новое место.

Щёлкни правой кнопкой по котозайцу, чтобы открыть настройки. Там меняются размер, высота относительно нижнего края, прикрепление к курсору и прогулка. В настройках можно отключить звуки прыжка и приземления. Звуки проигрываются локально через `pw-play` или `paplay`, без браузера и сети. Во время перетаскивания котозаяц переносится между подключёнными мониторами и запоминает выбранный экран. После перетаскивания котозаяц приземляется на новом месте и не сбрасывает X назад; координата запоминается между запусками. Отдельного ползунка X нет. Настройки сохраняются в `~/.config/kotozaytsy/settings.json`.

## Установка на Arch Linux

Если проект скачан с GitHub, запусти установщик из его папки: он сам проверит и поставит системные библиотеки, скопирует программу и включит автозапуск.

```sh
./install.sh
```

Для сборки пакета Arch (`.pkg.tar.zst`) из исходников:

```sh
makepkg -si
```

Пакет подтянет нужные зависимости автоматически.

Если устанавливать вручную, нужны:

```sh
sudo pacman -S python-gobject python-cairo gtk4 gtk4-layer-shell gdk-pixbuf2
```

## Запуск

Распакуйте папку в удобное место и запустите из неё:

```sh
./run.sh
```

Нужна сессия Wayland и Hyprland. Закрыть приложение можно кнопкой «Выйти» в настройках. `run.sh` подгружает библиотеку layer-shell в нужном порядке. `install.sh` включает автозапуск: в стандартном Hyprland это `~/.config/hypr/hyprland.conf`, а в Caelestia Lua-конфигурации — `~/.config/caelestia/hypr-user.lua`.

Для обычного Hyprland автозапуск можно добавить вручную:

```ini
exec-once = python /полный/путь/к/kotozaytsy.py
```
